# Image Importing

This page will dive into integrations via one of the three main categories:

* Image File Import



### Add Image to Note

When you create a new note there is an option within the initial window that enables you to upload an image to pair with the note. You can drop an image in the box, paste it, or click to bring up a window for importing.

<figure><img src="../.gitbook/assets/Screenshot 2026-07-21 at 1.42.01 AM.png" alt="" width="375"><figcaption></figcaption></figure>



The image will appear on the main page as a thumbnail but clickable to be enlarged.&#x20;

<figure><img src="../.gitbook/assets/Screenshot 2026-07-21 at 1.46.41 AM.png" alt=""><figcaption></figcaption></figure>



When you export your notes there will automatically be an additional page attached to the end of the document to display images you've imported.&#x20;

{% hint style="info" %}
IMAGE NOTES:

* Exports cap at 50 images.
* One image per note limit.
* Images are re-encoded to JPEG at max 1600px.
{% endhint %}
