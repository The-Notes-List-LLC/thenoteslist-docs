# Importing Your Script

This page will dive into integrations via one of the three main categories:

* Script Import



Cue Script importing can be very helpful in your note taking processes. Importing the script will allow TheNotesList to find the corresponding page number of your cue and add it to your export for a more efficient communication system.

{% hint style="warning" %}
NOTE: The "script" import is a CSV table of assigned columns that are listed below. This will enable your cue notes to be able to source corresponding page numbers for note export.
{% endhint %}

### Importing Your Script

#### From the main note taking window

In the top right corner select **Script.** A window will appear:

<figure><img src="../.gitbook/assets/Screenshot 2026-07-21 at 1.17.33 AM.png" alt=""><figcaption></figcaption></figure>

In this window you can:

* Upload a CSV or TSV file of a script breakdown&#x20;

OR

* Paste the values directly from a spreadsheet.&#x20;
