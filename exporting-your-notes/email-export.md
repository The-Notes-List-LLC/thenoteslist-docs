# Email Export

Let's work on setting up our email exporting presets so TheNotesList will be able to send out our reports with just a few clicks.



{% stepper %}
{% step %}
### Select Email Exporting

This can be found in the upper right corner of the note-taking window.

<figure><img src="../.gitbook/assets/Screenshot 2026-07-20 at 4.37.11 PM.png" alt="" width="563"><figcaption></figcaption></figure>
{% endstep %}

{% step %}
### Select Export Option

After you select your **Email**, a window will appear where you can choose your export method.

<figure><img src="../.gitbook/assets/Screenshot 2026-07-20 at 4.39.03 PM.png" alt="" width="563"><figcaption></figcaption></figure>

This window includes preset exporting options for all of the **Quick Add** instances in the note-taking window. These identify the selected portion of notes for specific export.

For now, Let's take a look at the **All To-Do** option, which will compile all notes taken in the module for export. Click the option to open it's window.

<figure><img src="../.gitbook/assets/Screenshot 2026-07-20 at 4.41.47 PM.png" alt="" width="563"><figcaption></figcaption></figure>
{% endstep %}

{% step %}
### Edit Export Option

<figure><img src="../.gitbook/assets/Screenshot 2026-07-20 at 4.46.50 PM.png" alt="" width="563"><figcaption></figcaption></figure>

In this window you can:

* Edit the subject line of the email
* Edit the body of the email
* View and Edit the details of the export
* Assign email addresses for export

Let's take a look at editing withing each section. To edit individual sections, hover your mouse above the area you'd like to edit. An icon will appear to the right side of the section, click it.

#### **"To"**

This field is to input email addresses of collaborators that you would like to receive this batch of exports. Emails should be seperated by commas to send to multiple recipients.&#x20;

Example: stagemanager@gmail.com, director@gmail.com, setdesigner@gmail.com

Click **Done** to close the editing window of this section.&#x20;

<figure><img src="../.gitbook/assets/Screenshot 2026-07-20 at 4.57.09 PM.png" alt="" width="563"><figcaption></figcaption></figure>

#### **"Subject"**&#x20;

This field is to input the subject heading of the emails you will be distributing for this batch of exports. TheNotesList provides customizable tokens within the subject line that help identify this exports qualities. These tokens include:

* Production Title (Included by Default)
* Note Module Name (Included by Default)
* User First Name
* User Last Name
* User Full Name
* Current Date (Included by Default)
* Current Time (Included by Default)

<figure><img src="../.gitbook/assets/Screenshot 2026-07-20 at 5.00.38 PM.png" alt=""><figcaption></figcaption></figure>

Click **Done** to close the editing window of this section.&#x20;

#### **"Body"**&#x20;

This field is to input the body of the emails you will be distributing for this batch of exports. TheNotesList provides customizable tokens within the body that help identify this exports qualities. These tokens include:

* Production Title
* Note Module Name
* User First Name
* User Last Name
* User Full Name (Included by Default)
* Current Date
* Current Time

<figure><img src="../.gitbook/assets/Screenshot 2026-07-20 at 5.06.30 PM.png" alt=""><figcaption></figcaption></figure>

TheNotesList will also populate the phrase "Please find the attached notes report" into the body of the email automatically but this can be customized or removed entirely.&#x20;

Once you have input the appropriate information, save your preset details. Next time you go to export your notes you are now able to do so using jsut the **Send Email** button.&#x20;
