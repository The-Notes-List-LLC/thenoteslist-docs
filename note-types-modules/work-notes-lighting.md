# Work Notes (Lighting)

We've explored setting up some cue notes already but let's discuss the **Work Notes** module, it's structure, and when it may fit your needs compared to other modules.

### Overview

The Work Notes module is designed to be a hub for lighting work notes but could be augmented to work for your departmental needs as well. One of the core benefits of using the Work Notes module is the ability to import your lighting hookup via CSV. ([See more about hookup integration here.](../integrations/importing-your-hookup.md))



### Page Layout

<figure><img src="../.gitbook/assets/Screenshot 2026-07-22 at 12.52.04 AM.png" alt=""><figcaption></figcaption></figure>

You'll notice the quick adds in the Work Notes module are different from those in the Cue Notes module. These are geared more towards the typical type of lighting work note you may have. The quick adds for the Work Notes module are:

* Work
* Focus
* Paperwork
* Electrician
* Think

As with any module, these are fully customizable in the settings window.

{% hint style="info" %}
NOTE: When disabling lighting capability, certain quick adds will not be in your notes window. These include focus and electrician.&#x20;
{% endhint %}

### Adding Work Notes

The process for adding notes is very similar to the Cue Notes module so let's just examine a few of the differences.&#x20;

Let's generate a focus note as an example. Say we noticed channel 36 could use an upstage cut. Let's select **\[ + Focus ]** and add that focus note. A window will open:

<figure><img src="../.gitbook/assets/Screenshot 2026-07-22 at 1.00.47 AM.png" alt="" width="563"><figcaption></figcaption></figure>

You'll find that this window is incredibly similar to the one for the **Cue Notes** module with a few notable difference:&#x20;

Instead of a tab for **Cue Number,** you are provided a tab to input the **Channel Expression** to identify the fixture corresponding to the work note.&#x20;

For this example I've already imported my channel hookup so when I input my channel number, "**36**", into the Channel tab, The Notes List found and populated the fixture information automatically.

### Order List Integration

Within the window for a new note in the **Work Notes** module, The Notes List provides an option to create a record of what materials may be needed to complete the note. This can be found in the **Add New Note** window by scrolling to the bottom of the window.&#x20;

For an example, I'm adding a work note for Channel 36 to get a frost change.&#x20;

<figure><img src="../.gitbook/assets/Screenshot 2026-07-22 at 1.35.35 AM.png" alt="" width="563"><figcaption></figcaption></figure>

By clicking **\[ + Add Order List ]** an addition to the window will appear. In this window you can input the item you wish to add to the **Order List.**&#x20;

<figure><img src="../.gitbook/assets/Screenshot 2026-07-22 at 1.38.45 AM.png" alt="" width="563"><figcaption></figcaption></figure>

{% hint style="info" %}
NOTE: You are able to delineate the type of item you are ordering with items in the dropdown menu autopopulated with "unit".
{% endhint %}

<figure><img src="../.gitbook/assets/Screenshot 2026-07-22 at 1.39.19 AM.png" alt="" width="375"><figcaption></figcaption></figure>

Once you have your item(s) configured, Click **\[ + Add ]** to place the item on the **Order List.**

Once added, the item will appear a few places within The Notes List. The first being within the note window itself. It will show the number of each item ordered and provide a checkbox to mark when the order is complete.

<figure><img src="../.gitbook/assets/Screenshot 2026-07-22 at 1.40.20 AM.png" alt="" width="563"><figcaption></figcaption></figure>

The second location being on the main Note Taking page. An added column will show the number of **\[ orders filled / orders total ]** right on the main page.

<figure><img src="../.gitbook/assets/Screenshot 2026-07-22 at 1.47.35 AM.png" alt=""><figcaption></figcaption></figure>

The final place you can view your Order List now that you've completed it is the **Order List** module. For more information on the Order List module, [click here.](order-list.md)&#x20;

<figure><img src="../.gitbook/assets/Screenshot 2026-07-22 at 1.49.57 AM.png" alt=""><figcaption></figcaption></figure>

### Work Note Columns&#x20;

Also to note about the **Work Notes** module would be the availability of lighting specific columns to view in the main notes area.&#x20;

<figure><img src="../.gitbook/assets/Screenshot 2026-07-22 at 1.08.43 AM.png" alt="" width="375"><figcaption></figcaption></figure>

These page specific columns include:

* **Channel(s)**
* **Fixture Type**
* **Purpose**
* **Position**

These lighting specific columns all come preset as viewed in the **Work Notes** module.

{% hint style="info" %}
Note: If applicable to your note, you could also add a photo into this note for added specificity.
{% endhint %}
