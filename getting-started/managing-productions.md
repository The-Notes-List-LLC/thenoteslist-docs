# Managing Productions

Setting up a production on The Notes List is quick and easy. On this page we will set up an example production.



{% stepper %}
{% step %}
#### Go to the Homepage and Select "New Production"

On the homepage you will find:&#x20;

* A clean layout of your existing productions
* A tab to access your billing
* A bin of disposed productions
* A tab to start your new production.&#x20;
{% endstep %}

{% step %}
<figure><img src="../.gitbook/assets/Screenshot 2026-07-20 at 2.36.10 PM.png" alt="A screenshot of The Notes List homepage." width="375"><figcaption><p>TheNotesList Homepage with Example Productions</p></figcaption></figure>
{% endstep %}

{% step %}
### Input Production Details

Here you will find the production creation page.&#x20;

Tabs include:

* Production Name
* Production Abbreviation
* A check box for lighting capability
* Note modules to include as a starting point.&#x20;

<figure><img src="../.gitbook/assets/Screenshot 2026-07-20 at 2.39.36 PM.png" alt="Screenshot of the production creation page. Tabs include; Production Name, Abbreviation, A check box for lighting capability, and note modules to include as a starting point." width="563"><figcaption></figcaption></figure>

{% hint style="warning" %}
NOTE: Lighting Capability is automatically checked. This creates a module tab for electrician notes and enables to ability to import your hookup for synced fixture information.
{% endhint %}

{% hint style="info" %}
TheNotesList will automatically create a production abbreviation for you, but you are always welcome to create your own.&#x20;
{% endhint %}

{% hint style="info" %}
NOTE: You can edit these starting modules anytime in **Settings -> Modules.**
{% endhint %}
{% endstep %}

{% step %}
#### Select "Create Production"

The green button in this window creates your production and automatically opens the main screen for your production;

You can see that The Notes List has populated your production name and abbreviation in the upper left hand side of the note-taking window.&#x20;

<figure><img src="../.gitbook/assets/Screenshot 2026-07-20 at 2.49.00 PM.png" alt=""><figcaption></figcaption></figure>
{% endstep %}
{% endstepper %}
