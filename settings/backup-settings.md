### Backups

The **Backups** tab can prove to be a cruical part of your workflow. You are able to export a JSON file as a full backup of your production at any time. You can then use that file to load the show from that save point or create a new production based off the file you've customized.&#x20;

This tab also has a function to save checkpoints of your production. Any of these checkpoints can be downloaded as complete JSON files.&#x20;
